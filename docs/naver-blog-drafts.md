# 커리어픽 네이버 블로그 발행 대기함

현재 상태: **전체 ALIO 공고 검수 초안 생성 단계**. 하루 11건 제한 없이 마감·미확인 공고도 경고와 함께 포함합니다. 네이버 로그인·임시저장·발행을 수행하지 않습니다.

## 수동 시험
GitHub Actions > Prepare Naver blog drafts (manual) > Run workflow 에서 이 개발 브랜치를 선택합니다.
완료 후 Artifacts의 `naver-blog-review-drafts`를 내려받습니다.

## 콘텐츠 검수 기준
- 원문에서 확인하지 않은 지원자격, 연봉, 경쟁률, 배점 등을 임의로 작성하지 않습니다.
- `alio.json`만으로는 첨부 모집요강을 완전히 분석할 수 없습니다.
- 마감 시각이 명시되지 않은 공고의 시각을 확정적으로 안내하지 않습니다.
- 현재 결과물은 Markdown 검수 초안입니다. Word·썸네일은 생성됩니다. AI 심층 해설·네이버 계정 임시저장은 아직 미구현입니다.
- 본 브랜치는 운영 중인 ALIO/Threads 자동화와 분리되어 있습니다.

## 다음 단계
공식 모집요강 상세 정보 및 첨부자료를 수집·검증하고, 첨부한 4단계 검색의도 프롬프트를 해설 엔진에 적용합니다. 이후 DOCX 및 인포그래픽 생성, 게시 대기 검수를 추가합니다.

## 전체 공고 보관
GitHub Actions 결과물에 모든 ALIO 공고의 Markdown·Word·썸네일을 보관합니다. 만료 공고는 현재 지원 가능한 공고로 안내하지 않습니다. 실제 네이버 임시저장 및 발행은 수행하지 않습니다.
