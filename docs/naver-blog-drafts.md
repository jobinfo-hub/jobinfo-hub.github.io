# 커리어픽 네이버 블로그 발행 대기함

현재 상태: **초안 생성 실험 단계**. 네이버 로그인·임시저장·발행을 수행하지 않습니다.

## 수동 시험
GitHub Actions > Prepare Naver blog drafts (manual) > Run workflow 에서 이 개발 브랜치를 선택합니다.
완료 후 Artifacts의 `naver-blog-review-drafts`를 내려받습니다.

## 콘텐츠 검수 기준
- 원문에서 확인하지 않은 지원자격, 연봉, 경쟁률, 배점 등을 임의로 작성하지 않습니다.
- `alio.json`만으로는 첨부 모집요강을 완전히 분석할 수 없습니다.
- 마감 시각이 명시되지 않은 공고의 시각을 확정적으로 안내하지 않습니다.
- 현재 결과물은 Markdown 검수 초안입니다. Word·이미지·AI 해설·네이버 임시저장은 아직 미구현입니다.
- 본 브랜치는 운영 중인 ALIO/Threads 자동화와 분리되어 있습니다.
