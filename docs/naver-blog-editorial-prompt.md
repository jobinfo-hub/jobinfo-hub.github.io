# 커리어픽 네이버 채용 해설 생성 지침 v1

## 입력
- 커리어픽 ALIO 데이터(기관명·공고명·접수기간·지역·직무·인원·원문 링크)
- 확인 가능한 공식 모집요강/첨부파일 전문과 출처 URL
- 공고별 커리어픽 상세페이지 URL

## 1단계: 검색 의도
검색자가 실제 궁금해할 질문 10개를 도출한다. 자격, 지원기간, 급여, 전형, 가점, 근무지, 서류, 경쟁률, 중복지원 등을 공고 내용에 맞게 조정한다.

## 2단계: 차별화
동일 키워드 상위 글 3개를 실제로 조회할 수 있을 때만 비교한다. 조회할 수 없으면 '경쟁 글 미검증'으로 기록한다. 경쟁 글에서 누락된 실질적인 질문을 우선 설명한다. 분석하지 않았는데 분석했다고 쓰지 않는다.

## 3단계: 글 작성
- 첫 3줄에 모집기관·핵심 자격·정확한 접수 마감(확인된 경우)을 먼저 제시한다.
- 제목: 기관명 + 공고명 + 핵심 차별점. 과장된 합격 보장 표현 금지.
- 순서: 결론 요약 → 인원·직무 → 지원자격 → 근무조건 → 전형/가점 → 일정 → FAQ → 제출 전 체크리스트 → 공식 출처 → 커리어픽 해당 공고 CTA.
- 공식 모집요강에 없는 점수·급여·경쟁률·제외조건은 만들지 않는다.
- 확인되지 않은 항목은 '공식 공고에서 확인 필요'로 표기한다.
- 원문에서 확인된 사실과 '커리어픽 해설/제안'을 구분한다.
- 공고마다 질문과 소제목을 실제 조건에 맞게 바꾼다. 10개 질문을 무조건 본문에 복제하지 않는다.
- 날짜는 한국시간으로 표시하고 마감일 변경 가능성을 명시한다.
- HTML, 이미지 설명, DOCX 등 출력 매체에 따라 내용의 정확성을 동일하게 유지한다.

## 4단계: 검수
질문 10개 중 답변 완료/공고 미기재/추가 확인 필요를 분류한다. 출처가 없는 숫자·조건은 게시 전 차단한다. 링크 접근, 공고 마감 여부, 제목 중복, 개인정보 노출 여부를 검사한다.

## 이미지
원문에 근거한 모집인원 차트, 일정표, 지원 전 체크리스트를 우선한다. 수치가 없는 경우 가상 그래프를 만들지 않는다. 출처와 기준일을 이미지 설명에 기록한다.

## 발행
네이버 블로그 발행 및 임시저장은 수행하지 않는다. 모든 산출물은 검수 대기 상태로 저장한다. 사용자가 최종 발행한다.
